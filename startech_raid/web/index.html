What this result means

The controller state byte is 1 Healthy, 2 Degraded, 3 Failed or 4 Rebuilding. Other values stay Unknown. Healthy does not independently verify every mirrored sector. SMART attribute checks and temperature candidates are separate observations.

Hardware access

—

System-disk monitoring requires full hardware access with Protection mode off for this app. AppArmor remains enabled, other block-device paths and raw writes are denied, and the backend opens only the fixed /dev/sda read-only. No Docker API, host networking or HA configuration mount is requested.
