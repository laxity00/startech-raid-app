# StarTech RAID Monitor — private app

Install alongside the private `startech_raid` companion integration. See DOCS.md for the complete installation, permissions, entities, dashboards, logs and rollback guide.

This release contains only authored software plus the unchanged, tested v0.2.0 ARM64 monitor. No downloaded firmware or vendor utilities are included. No public repository/image is published. Intended target is the user's pinned StarTech SM22BU31C3R / 161028_B5_30_81 on Pi 4 HAOS.
